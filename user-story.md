# User Story Template

**Title:**
As a [user role], I want [feature/goal] so that [reason/benefit].

**Acceptance Criteria:**
1. [Criterion 1]
2. [Criterion 2]
3. [Criterion 3]

**Priority:** [High / Medium / Low]
**Story Points:** [estimate]
**Notes:** [extra context]

---

## Example 1 – Post an item
**Title:** As a donor, I want to post an item I no longer need so that someone nearby can pick it up for free.
**Acceptance Criteria:**
1. Form accepts name, category, condition, description and image.
2. Item appears on the main page after submission.
3. Only logged-in users can post.

## Example 2 – Search
**Title:** As a seeker, I want to search items by name and category so that I can quickly find what I need.
**Acceptance Criteria:**
1. Search supports name, category, condition and age filters.
2. Results update without page reload.
3. A "no results" message is shown when nothing matches.
